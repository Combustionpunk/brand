# RC Misfits logo

| File | Use |
|---|---|
| `rc-misfits-logo.svg` | Master. Use this everywhere it can be used (web, timing screens, forum header). |
| `rc-misfits-logo.png` | 2463×1041 transparent PNG, for places that can't take SVG. |

- Colours: white sticker border `#FFFFFF`, outline `#000000`, letters `#C7C6C6`, stars `#FFED00`.
- The white sticker border is part of the logo, so it works on any background (dark, light or club colour).
- Don't recolour, stretch, or add effects. Themes change the UI around the logo, not the logo itself.
- The SVG is a trace of the PNG (Nov 2026). A hand-drawn master can replace it later under the same file name.
